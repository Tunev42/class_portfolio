# 🎓 Сайт-портфолио класса

Современный веб-сайт для школьного класса, созданный на Python и Flask. Позволяет ученикам и учителям делиться достижениями, просматривать фотогалерею, расписание и актуальные олимпиады, которые автоматически подгружаются из интернета.

> **Проект разработан с упором на безопасность, удобство использования и отказоустойчивость.**

---

## ✨ Возможности проекта

- 🔐 **Система авторизации и ролей**: Разделение прав для учеников, учителей и администраторов.
- 🛡️ **Модерация контента**: Ученики могут предлагать достижения с фото-доказательствами, которые публикуются только после проверки учителем.
- 🌐 **Автоматический парсер олимпиад**: Сайт самостоятельно скачивает актуальный список олимпиад с открытых источников (например, olimpiada.ru) с помощью `BeautifulSoup`.
- 🌓 **Адаптивный дизайн**: Поддержка светлой и тёмной темы с сохранением выбора пользователя в браузере.
- 📸 **Галерея и расписание**: Удобные страницы для просмотра фото и уроков с адаптивной вёрсткой.

## 🚀 Быстрый старт

Следуй этим инструкциям, чтобы запустить проект на своём компьютере:

### 1. Клонируй репозиторий
```bash
git clone https://github.com/ТВОЙ_НИК/class_portfolio.git
cd class_portfolio
```

### 2. Создай виртуальное окружение и активируй его
**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```
**macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установи зависимости
```bash
pip install -r requirements.txt
```

### 4. Запусти приложение
```bash
python app.py
```
После запуска в консоли появится сообщение о создании тестовых пользователей, а сайт будет доступен по адресу: `http://127.0.0.1:5000`

## 💡 Особенности реализации

1. **Безопасность**: Пароли хранятся только в виде хешей (библиотека `Werkzeug`). Загружаемые файлы проходят проверку через `secure_filename`, чтобы предотвратить атаки на файловую систему.
2. **Отказоустойчивость парсера**: Если внешний сайт недоступен или изменил структуру, функция `get_fallback_olympiads()` автоматически выдаст проверенные резервные ссылки, чтобы страница не выглядела пустой.
3. **UX/UI**: Все формы имеют валидацию на стороне клиента (`required`, `minlength`) и сервера, а интерфейс адаптируется под мобильные устройства.
